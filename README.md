# Java Exercises

A collection of Java exercises I wrote while learning the language, organized by topic. The exercises and their output messages are in Portuguese.

## Topics

| Package | Content |
|---|---|
| [`basics`](src/basics) | First lessons: primitive types, operators, reading input with `Scanner`, `if`/`else` and `switch` |
| [`fundamentals`](src/fundamentals) | Input and output with `Scanner`, operators and sequential calculations |
| [`conditionals`](src/conditionals) | `if`/`else`, the ternary operator and classification problems |
| [`loops`](src/loops) | `for`, `while` and `do-while` |
| [`arrays`](src/arrays) | Declaring, filling and traversing arrays, including the for-each loop |
| [`classes`](src/classes) | Classes and objects, getters and setters, method overloading and `static` members |
| [`oop`](src/oop) | Exercises with classes, constructors, encapsulation and `static` members |
| [`inheritance`](src/inheritance) | `extends` and `super` |
| [`abstractclasses`](src/abstractclasses) | Abstract classes and abstract methods |
| [`interfaces`](src/interfaces) | Interfaces, interface inheritance, `default` and `static` methods |
| [`polymorphism`](src/polymorphism) | Referring to subclasses through their parent type |
| [`finalkeyword`](src/finalkeyword) | `final` variables, methods and classes |
| [`annotations`](src/annotations) | `@Override`, `@Deprecated` and `@SuppressWarnings` |
| [`collections`](src/collections) | `List`, `Set` and `Map` |
| [`hashmap`](src/hashmap) | Practice drills with `HashMap` |
| [`codesignal`](src/codesignal) | Multi-level CodeSignal-style challenges, each with an interface and its implementation |

LeetCode solutions are in a separate repository: [data-structures-and-algorithms](https://github.com/arthurnorat/data-structures-and-algorithms).
